# توضیح پروژه برای استاد و ارائه دانشگاهی

## معرفی آماده برای گفتن

«termoyazd یک ابزار تحت مرورگر برای محاسبه خواص آب و بخار است. کاربر یکی از یازده زوج خاصیت را وارد می‌کند و نرم‌افزار خواص باقیمانده را با فرمول‌بندی صنعتی IAPWS-IF97 محاسبه می‌کند. در کنار جواب، فاز، ناحیه، کیفیت در حالت تعریف‌شده و اطلاعات روش حل نیز گزارش می‌شود. هدف پروژه فقط نمایش عدد نیست؛ تشخیص ورودی نامعتبر، حالت مبهم و کنترل خطای عددی هم بخش اصلی طراحی بوده است.»

## بخش‌های مهندسی که باید توضیح دهید

۱. **درجه آزادی حالت:** دو خاصیت مستقل معمولاً حالت را مشخص می‌کنند؛ روی اشباع، دما و فشار مستقل نیستند. بنابراین نرم‌افزار نباید با T/P اشباع، کیفیت فرضی بسازد.
۲. **فرمول‌بندی:** کتابخانه iapws منبع محاسبه است. جدول PDF ابزار مقایسه است و داده نمایشی تصویر داشبورد، مرجع علمی نیست.
۳. **حل معکوس:** برای زوج‌هایی مانند T+h، فشار مجهول است. دامنه فشار به ناحیه‌های مناسب تقسیم و ریشه اختلاف آنتالپی محاسبه‌شده با مقدار ورودی جست‌وجو می‌شود. سپس ورودی‌ها دوباره بازسازی می‌شوند.
۴. **چند جواب:** به‌ویژه نزدیک ناهنجاری چگالی آب، یک زوج ورودی می‌تواند چند حالت ایجاد کند. برنامه چند جواب پیدا‌شده را پنهان نمی‌کند. جست‌وجوی محدود نیز اثبات یافتن همه ریشه‌ها نیست.
۵. **واحد:** تبدیل واحد در مرز رابط انجام می‌شود و موتور قرارداد مشخص °C/kPa دارد؛ داخل iapws از K/MPa استفاده می‌شود.
۶. **نمودار:** هر نقطه مرز اشباع از حل واقعی مایع و بخار اشباع به دست می‌آید. نزدیک نقطه بحرانی محدودیت رسم صریح اعلام شده است.

## معماری به زبان ساده

React مسئول فرم و نمایش است؛ FastAPI قرارداد دریافت و پاسخ را مدیریت می‌کند؛ موتور Python مسئول علم و حل عددی است؛ SciPy ابزار یافتن ریشه است؛ Plotly نمودارها را تعاملی می‌کند. یک مسیر دیگر، اجرای همین Python در مرورگر با Pyodide است؛ در آن حالت کاربر نیاز به نصب Python ندارد و محاسبه روی دستگاه خودش انجام می‌شود.

## نمایش پیشنهادی ۵ تا ۷ دقیقه‌ای

- نام و مسئله پروژه را معرفی کنید و زوج T+P را نشان دهید.
- T=300 °C و P=500 kPa را واقعاً محاسبه و کارت‌ها را با واحد بخوانید.
- یک زوج P+x با کیفیت بین صفر و یک اجرا کنید و تفاوت کیفیت با درصد حجمی را بگویید.
- یکی از حل‌های معکوس را با ورودی معتبر امتحان کنید و هشدار یکتایی را توضیح دهید.
- نمودار، محور لگاریتمی و مرز اشباع را نشان دهید.
- با تغییر ورودی نشان دهید نتیجه قبلی پاک می‌شود.
- یک کیفیت نامعتبر وارد کنید تا نشان دهید برنامه خطای علمی را گزارش می‌کند.
- داده و گزارش validation را باز کنید و درباره اختلاف جدول‌ها صادقانه صحبت کنید.
