# راهنمای استفاده از termoyazd

## شروع محاسبه

۱. در Property Calculator (محاسبه خواص)، یکی از یازده زوج ورودی را انتخاب کنید.
۲. دقیقاً دو فیلد مربوط به آن زوج ظاهر می‌شود. واحد هرکدام را قبل از واردکردن مقدار بررسی کنید.
۳. عدد اعشاری یا نماد علمی مانند `1e3` وارد کنید. فشار باید مطلق باشد.
۴. Calculate (محاسبه) را بزنید و تا پایان محاسبه صبر کنید. بار اول موتور مرورگری ممکن است نیاز به دریافت فایل‌های حجیم داشته باشد.
۵. چهار کارت نتیجه، ورودی‌های نرمال‌شده و اطلاعات فاز/ناحیه را بررسی کنید. هشدار علمی جزئی از نتیجه است.

## واحدها

| خاصیت | واحدهای انتخابی |
|---|---|
| دما | °C و K |
| فشار | kPa، MPa و bar |
| کیفیت بخار | کسر جرمی kg/kg و درصد |
| آنتالپی و انرژی داخلی | kJ/kg و J/kg |
| آنتروپی | kJ/(kg·K) و J/(kg·K) |
| حجم ویژه | m³/kg و L/kg |

مثلاً کیفیت ۲۵ درصد همان x=0.25 است؛ ۱ MPa برابر ۱۰۰۰ kPa است. واردکردن فشار گیج بدون تبدیل به مطلق نتیجه فیزیکی متفاوتی می‌دهد.

## خواندن نتیجه

- Inputs: داده‌هایی که شما تعیین کرده‌اید، پس از تبدیل واحد.
- Results: چهار خاصیت باقیمانده؛ واحد کنار مقدار مهم است.
- Phase: توصیف فاز مانند مایع فشرده یا بخار فوق‌گرم.
- Region: شماره ناحیه فرمول‌بندی IF97؛ با نام فاز یکی نیست.
- Quality: سهم جرمی بخار در مخلوط اشباع. خارج از دامنه اشباع تعریف نمی‌شود.
- Saturation: دما یا فشار مرز اشباع مرتبط؛ حضور این اطلاعات به تنهایی به معنی اشباع بودن حالت نیست.
- Convergence: باقیمانده‌های بازسازی ورودی، تلرانس و وضعیت جست‌وجو.

برای T+x و P+x، چهار کارت h/u/s/v هستند و فشار یا دمای اشباعِ وابسته جدا گزارش می‌شود. نتایج حل معکوس ممکن است دارای هشدار اثبات‌نشدن یکتایی سراسری باشند؛ این هشدار را در گزارش دانشگاهی حذف نکنید.

## نمودارها

T–s رفتار دما و آنتروپی، P–v فشار و حجم ویژه، و P–h فشار و آنتالپی را نشان می‌دهند. منحنی‌های اشباع با IF97 محاسبه شده‌اند. ابزارهای Plotly برای بزرگ‌نمایی، جابه‌جایی، بازنشانی و ذخیره تصویر در دسترس‌اند. محور فشار در نمودارهای P–v/P–h لگاریتمی است؛ در P–v حجم هم لگاریتمی است. قسمت نهایی نزدیک رأس بحرانی رسم نشده است. اگر حل یکتا تأیید نشده باشد، نقطه حالت روی نمودار قرار نمی‌گیرد.

## خطاهای رایج

| پیام یا وضعیت | اقدام درست |
|---|---|
| T و P روی اشباع‌اند | یکی را همراه کیفیت یا خاصیت مستقل دیگر بدهید |
| کیفیت بیرون صفر تا یک | واحد درصد/کسر و مقدار را اصلاح کنید |
| چند حالت ممکن | اطلاعات فیزیکی مستقل بیشتری لازم است؛ جواب دلخواه انتخاب نکنید |
| جست‌وجو ناقص است | این یک نتیجه موفق نیست؛ تشخیص‌های علمی را بررسی کنید |
| مقدار خارج از دامنه | حدود IF97 و واحد ورودی را بررسی کنید |
| اتصال به API برقرار نیست | سرویس، آدرس و CORS باید بررسی شوند |

با تغییر ورودی، واحد یا زوج انتخابی، نتیجه قبلی پاک می‌شود. Clear/Reset برای شروع دوباره و Copy برای کپی JSON نتیجه معتبر است. عددهای نمونه، اگر انتخاب شوند، فقط ورودی را پر می‌کنند و بدون اجرای موتور خروجی موفق نمی‌سازند.

Excel، محاسبه گروهی و خروجی PDF در نسخه فعلی وجود ندارند. برای استاد، لینک مخزن امکان مطالعه کد را می‌دهد؛ استفاده مستقیم بدون نصب، نیازمند انتشار واقعی سایت است.
