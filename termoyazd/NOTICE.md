# Sources, dependencies and licensing boundaries

termoyazd uses React, TypeScript, Vite, Tailwind CSS, Plotly.js, FastAPI, Pydantic, iapws, NumPy, SciPy, Pyodide and additional transitive dependencies. Their respective licenses apply; inspect the installed distributions and package metadata for exact versions and notices. This document does not grant rights on behalf of those projects.

Scientific formulation references include the official IAPWS-IF97 release and the iapws documentation linked in [scientific model](docs/SCIENTIFIC_MODEL.md). The privately supplied SteamTableSI.pdf is not redistributed in the GitHub source tree. Its hash, limited transcribed validation points and provenance are recorded in the validation dataset; no claim of ownership of that source is made.

No new project-wide license is selected by this documentation update. Preserve any existing repository licensing files. Public visibility alone is not an unrestricted license grant. The owner should choose an explicit license before broader redistribution under a declared license.

termoyazd is not presented as an IAPWS-endorsed or certified product.
